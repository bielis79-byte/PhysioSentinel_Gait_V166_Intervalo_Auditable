# PhysioSentinel Gait Version 162

Versión derivada de V161 que corrige la continuidad temporal de los pies,
restaura la piel SKEL original y valida la posición anterior de las rótulas.

Descomprime el ZIP conservando todos los archivos en la misma carpeta. El punto
de entrada de Streamlit es `streamlit_app.py`.

La carga del NPZ y del atlas Denver se mantiene igual. La aplicación muestra el
resultado del control anatómico V162 antes de habilitar la anatomía Denver.
